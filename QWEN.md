# TubeNauta V5 - Masivo IMG

## Project Overview

**TubeNauta V5** is an automated batch video generation system for YouTube Shorts (1080×1920, 40–70s). It takes a list of topics or news stories and runs them through a **7-step AI pipeline** to produce fully narrated videos with AI-generated scripts, TTS voice, Whisper subtitles, Flux-generated images, and FFmpeg assembly.

### Key Features
- **Batch processing** from `temas.txt` (one topic per line) or `noticias.txt` (news stories separated by `---`)
- **AI-powered** script generation via Gemini (with Ollama/gemma3:4b fallback)
- **TTS narration** using Gemini's text-to-speech (voice: Algieba, Spanish neutral)
- **Word-level subtitles** via Whisper large-v3
- **Scene images** generated by Flux via ComfyUI REST API
- **FFmpeg assembly** with h264_nvenc encoding, zoom-pan effects, ASS subtitles, and subscribe banner
- **Resumable pipeline** — skips already-completed steps (checks output file existence)
- **Flask web interface** with SSE real-time log streaming

## Architecture

### 7-Step Pipeline (`pipeline.py`)

Each topic/news story runs through these **sequential steps**:

1. **Guion** (Script) — AI generates 61–70s script (`2. Guion.txt`)
2. **Metadatos** (Metadata) — Title, description, tags (`3. Metadatos.txt`)
3. **Voz** (Voice/TTS) — Gemini TTS → `4. Crudo.wav` + compressed `5. Voz.mp3`
4. **Subtítulos** (Subtitles) — Whisper word-level → `6. Subtitulos.srt`
5. **Escenas** (Scenes) — Segment subtitles (min 2.5s), generate English visual prompts → `7. Escenas.csv`
6. **Imágenes** (Images) — Flux via ComfyUI API (1024×1536) → `imagenes/{start}_{end}_1.png`
7. **Video** (Final) — FFmpeg with zoom-pan, ASS subtitles, banner overlay → `8. Video.mp4`

## Building and Running

### Prerequisites

- **ComfyUI** running at `http://127.0.0.1:8188` with Flux configured
- **Ollama** with `gemma3:4b` model loaded
- **FFmpeg** and **FFprobe** in PATH
- **Environment variable**: `GEMINI_API_KEY`
- (Optional) Google Search API keys for news verification

### Install Dependencies

```bash
# Core dependencies
pip install openai ollama google-generativeai pydub torch transformers pandas flask requests

# Web interface additional
pip install -r requirements-web.txt
```

### Running

```bash
# Batch video generation from temas.txt
python main.py

# Single topic(s) via CLI
python main.py "Topic 1" "Topic 2"

# News-based videos from noticias.txt
python news_runner.py

# Web interface at http://localhost:5000
python app.py
```

## Configuration

All tuneable parameters are in `config.py`:

| Setting | Default | Notes |
|---|---|---|
| `GEMINI_MODEL` | `gemini-2.5-flash` | Text generation |
| `GEMINI_TTS_MODEL` | `gemini-2.5-flash-preview-tts` | Audio generation |
| `OLLAMA_MODEL` | `gemma3:4b` | Local fallback LLM |
| `COMFYUI_URL` | `http://127.0.0.1:8188` | Local ComfyUI endpoint |
| `IMAGE_WIDTH/HEIGHT` | `1024×1536` | Flux output (portrait) |
| `VIDEO_WIDTH/HEIGHT` | `1080×1920` | Final video (Shorts format) |
| `TTS_VOICE` | `Algieba` | Spanish neutral voice |
| `SEGMENT_MIN_DURATION` | `2.5s` | Minimum scene duration |
| `WHISPER_MODEL` | `openai/whisper-large-v3` | Speech recognition model |

### Image Style Selection

Change style by setting `TUBENAUTA_ESTILO` env var or writing to `.estilo_temp.txt`. Available styles are defined in `estilos_imagen.py` (25+ styles including narrative, cinematic, anime, Pixar, horror, etc.).

## Important Implementation Details

- **AI Fallback Chain**: `chat()` tries Gemini first, falls back to Ollama on failure. Prompts loaded from `prompts/` directory as templates with `{placeholder}` substitution.
- **Windows/CUDA workaround**: `ai_utils.py` monkey-patches `sys.modules['torchcodec'] = None` before importing Whisper to avoid Windows-incompatible dependency. Audio pre-converted to 16kHz mono via pydub.
- **ComfyUI node IDs**: Defined in `config.py → FLUX_NODOS` — must match the loaded workflow JSON.
- **ANATOMY_FIX**: Anti-defect string appended to every Flux prompt.
- **BIOGRAPHY vs ORIGINAL mode**: Scene prompt generator detects historical/celebrity topics and switches to character-consistency mode.
- **Video extension**: If TTS audio longer than assembled video, FFmpeg `tpad` filter extends last frame.
- **FFmpeg paths**: `escapar_ruta_windows()` handles Windows path escaping for FFmpeg filter arguments.
- **NVENC encoding**: Uses `h264_nvenc` for GPU-accelerated encoding.

## Web Interface (`app.py`)

- Flask server with SSE for real-time log streaming
- Pipelines run as subprocesses for isolation
- Thread-safe log queue with `threading.Lock`
- Routes: `/` dashboard, `/temas`, `/noticias`, `/progreso` (SSE logs), `/galeria`, `/config`
- API: `POST /api/start`, `GET /api/status` (SSE), `GET /api/download/<path>`

## Development Conventions

- Variable/function names and comments are in **Spanish**
- Pipeline progress logged with Unicode: `✔` success, `✗` error, `↻` resuming, `[N/7]` step progress
- Output files use numbered prefixes (`1. Tema.txt`, `2. Guion.txt`, etc.) for visual ordering
- Constants use `UPPER_SNAKE_CASE`; module-level functions use `snake_case` in Spanish
- Code is well-documented with docstrings and section dividers
